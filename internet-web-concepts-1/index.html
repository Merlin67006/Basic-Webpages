Internet and World Wide Web

1. Internet Overview

The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate, share information and access various online services. 

    Computer A  --------\
                         \
                          INTERNET -------- Web Server
                         /
    Computer B  --------/

2. Fundamental Computer Network Concepts

A computer network is a group of computers and devices connected together to communicate and share resources.

  • IP Address: A unique address used to identify a device.
  • Protocol: A set of rules used for communication.
  • Router: Connects different networks and forwards data.
  • TCP/IP: A set of protocols used for Internet communication.
  • HTTP/HTTPS: Protocols used for communication between browsers and web servers.
    Computer ---- Router ---- Internet ---- Server

3. URL and its Structure

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Internet.

Example: https://www.example.com/products 

    https://www.example.com/products
    |       |       |       |
    |       |       |       +---- Path
    |       |       +------------ Domain Name
    |       +-------------------- Subdomain
    +---------------------------- Protocol
  • https: Protocol
  • www: Subdomain
  • example.com: Domain name
  • /products: Path

4. Domain Name

A domain name is a human-readable name used to identify a website on the Internet.

Example: www.google.com 

    www.google.com
        |     |
        |     +---- Top-Level Domain (.com)
        |
        +---------- Domain Name (google)

5. Web Browsers and Web Servers

Web Browser

A web browser is software used to access and display websites. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge and Safari.

Web Server

A web server is a computer or software system that stores website files and provides them to users when requested. 

    Web Browser (Client)
             |
             |  Request
             ↓
       Web Server
             |
             |  Response
             ↓
    Web Browser

6. Working Principle of a Website

A website works using communication between a client (web browser) and a web server.

  1. The user enters a URL in the web browser.
  2. The browser sends a request to the web server.
  3. The web server processes the request.
  4. The server sends the requested webpage to the browser.
  5. The browser displays the webpage to the user.
    User
      |
      ↓
    Browser
      |
      | Request
      ↓
    Web Server
      |
      | Response
      ↓
    Browser
      |
      ↓
    Webpage displayed to User

Conclusion

The Internet connects computers around the world, while the World Wide Web provides websites and web services through browsers and web servers. URLs and domain names help users locate websites, and client-side and server-side scripting help websites provide interactive and dynamic content.
